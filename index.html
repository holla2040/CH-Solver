How it works

Rules are equations, not assignments. a + b = c / d can be solved for any of its four variables, whichever one is unknown.

  1. Type rules in the Rule Sheet, one per line. Their variables appear in the Variable Sheet.
  2. Type known values in the Input column.
  3. Press ! (or F9). Answers appear in the Output column.

Guesses and iteration

When no rule has a single unknown, the direct solver gets stuck. Give a variable a starting value and set its St to G. The iterative solver adjusts the guesses with Newton–Raphson until every rule balances. With Auto-guess on, CH!Solver picks guess variables itself, starting at 1.

Lists and plots

Set St to L, enter values on the Lists tab (or use Fill), then choose List Solve. Each row is solved in turn and output lists are filled and plotted.
